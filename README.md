# autolife-lead-bot

Telegram-бот канала «Авто Жизнь с Мирой»: принимает заявки через короткий опрос
из 4 вопросов и передаёт их Ольге.

## Почему stateless

Состояние диалога кодируется прямо в тексте сообщения (`[state:шаг:данные]`).
Сервер не хранит ничего на диске, поэтому перезапуск, деплой или смена инстанса
ничего не ломают. Заявки уходят сразу в Telegram — в личку ADMIN_ID и, если задан
LEAD_CHAT_ID, в отдельный чат-канал. Их невозможно потерять.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен Telegram-бота (обязательно) |
| `ADMIN_ID` | id получателя заявок (по умолчанию 1213874390) |
| `LEAD_CHAT_ID` | id чата-канала для заявок (необязательно) |
| `WEBHOOK_SECRET` | секрет для проверки заголовка `X-Telegram-Bot-Api-Secret-Token` |
| `LANDING_URL` | ссылка на лендинг в тексте заявки |
| `CHECKLIST_URL` | ссылка на чек-лист в тексте заявки |

`RENDER_EXTERNAL_URL` и `PORT` проставляются Render автоматически.

## Деплой

Render → New → Blueprint → указать репозиторий. Значения переменных задаются
вручную в панели (в `render.yaml` они помечены `sync: false`).

После деплоя один раз открыть `https://<имя-сервиса>.onrender.com/setwebhook`
— бот зарегистрирует webhook. Дальше он работает сам.

## Локальный запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN=... ADMIN_ID=...
python bot.py
```

## Проверка

`GET /health` → 200. Основной endpoint — `POST /webhook`.

# autolife-lead-bot

Telegram-бот канала «Авто Жизнь с Мирой»: принимает заявки через короткий опрос
из 4 вопросов и передаёт их Ольге.

## Как это работает

* **Long polling.** Внешний HTTPS-адрес не нужен — бот сам забирает обновления
  у Telegram. Это позволяет задеплоиться на бесплатный тариф.
* **Stateless.** Состояние диалога кодируется прямо в тексте сообщения
  (`[state:шаг:данные]`). Сервер не хранит ничего на диске, поэтому перезапуск
  или пересборка контейнера ничего не ломают.
* **Заявки уходят сразу в Telegram** — в личку `ADMIN_ID` и, если задан
  `LEAD_CHAT_ID`, в отдельный чат-канал. Их невозможно потерять: они лежат
  в Telegram, а не на диске сервера.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен Telegram-бота. На Bothost подставляется платформой автоматически |
| `ADMIN_ID` | id получателя заявок |
| `LEAD_CHAT_ID` | id чата-канала для заявок (необязательно) |
| `LANDING_URL` | ссылка на лендинг в тексте заявки |
| `CHECKLIST_URL` | ссылка на чек-лист в тексте заявки |
| `DATA_DIR` | каталог для служебных файлов, проставляется платформой (`/app/data`) |

Токен **не хранится в репозитории** — он передаётся площадкой при создании бота.

## Деплой на Bothost

1. Зарегистрироваться на https://bothost.ru (без карты, тариф Starter — 0 ₽/мес).
2. Открыть https://bothost.ru/create-bot.php и заполнить:
   * Название — любое
   * Платформа — Telegram
   * Bot Token — токен от @BotFather
   * Git URL — `https://github.com/abakumiha72-gif/autolife-lead-bot.git`
   * Ветка — `main`
3. Нажать «Создать бота» и смотреть логи во вкладке «Деплой».

Точка входа определяется автоматически (`main.py`); в корне лежит `bothost.json`
с явным указанием. Свой Dockerfile не нужен.

## Локальный запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN=123456:ABC ADMIN_ID=1213874390
python main.py
```
